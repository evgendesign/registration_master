# Мастер регистрации ИП

Интерактивный прототип по макету Figma. Статическое приложение на HTML, CSS и JavaScript: сборка и сторонние зависимости не нужны.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Демо

Публикация: <https://evgendesign.github.io/registration_master/>

Мастер показывает выбор региона, формы бизнеса, деятельности и налогового режима, а также последующие шаги регистрации. Все введенные значения хранятся только в памяти открытой вкладки. Демо не сохраняет персональные данные, не запрашивает номера или изображения документов, не создает электронную подпись и не отправляет заявление.

## Публикация

GitHub Actions публикует содержимое репозитория на GitHub Pages при каждом обновлении ветки `main`.
