# Мастер регистрации ИП

Локальный интерактивный прототип на HTML, CSS и JavaScript без сборки и сторонних зависимостей.

## Запуск

Откройте `index.html` в браузере. Можно также запустить локальный сервер из этой папки:

```bash
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Публикация

GitHub Actions автоматически публикует содержимое репозитория на GitHub Pages при каждом push в `main`.

Все данные формы используются только для демонстрации на странице и никуда не отправляются.
